## Notes de méthode — corrections importantes pour la prochaine passe

⚠️ **Cette section corrige deux conclusions de la passe v2.**

### 1. Le CAPTCHA n'est pas une limite du site — c'est une limite du navigateur utilisé
v2 concluait que les URL `/w/wholesale-*` déclenchent un CAPTCHA et que la découverte par
recherche est bloquée. **C'est faux dans le bon navigateur.** Dans le Chrome réel de Hakim
(outils `claude-in-chrome`, session AliExpress connectée), **zéro CAPTCHA** sur :

- la recherche globale `https://fr.aliexpress.com/w/wholesale-<mots-cles>.html` — 12-14 fiches ;
- la recherche **dans une boutique**, qui est la vraie découverte :
  `https://fr.aliexpress.com/store/<id>/pages/all-items.html?SearchText=<mots>` — **40 fiches**,
  soit bien plus que les 30-40 de la page boutique brute, et filtrable par mot-clé.

Le blocage observé en v2 vient très probablement d'un navigateur **sans session** : le
navigateur d'aperçu isolé (`mcp__Claude_Browser__`) se fait servir
`fr.aliexpress.com/wp.html` (challenge anti-bot), la page charge ses images mais
**n'hydrate jamais** son contenu texte — d'où l'impression de listings morts. Aucun CAPTCHA
n'a été contourné durant cette passe : le challenge a simplement disparu en changeant de
navigateur.
→ **À retenir : toujours utiliser le Chrome de l'utilisateur pour AliExpress.**

### 2. Les « ~60 % de listings morts » étaient en grande partie un artefact d'extraction
Erreur commise puis corrigée au milieu de cette passe : j'ai d'abord tronqué les identifiants
aux 9 derniers chiffres pour tenir dans la limite de sortie, puis **reconstruit le préfixe au
jugé** (`1005007` / `1005008` / `1005009`). Résultat : des URL fabriquées qui renvoient un
404 alors que le produit est vivant. Les préfixes réels montent aujourd'hui jusqu'à
**`1005012`**.
→ **Toujours extraire les 16 chiffres complets de l'identifiant. Ne jamais deviner un préfixe.**
Une fois corrigé, le taux de listings réellement morts est très faible.

### 3. Extraction : `runParams.data` est désormais vide
`window.runParams.data` renvoie `{}` sur les fiches produit (plus de `sellerComponent`,
`titleComponent`…). Tout passer par le DOM :

- titre : `document.querySelector('h1').innerText` ;
- note / avis / ventes / prix : les ~250 premiers caractères de `document.body.innerText`
  à partir de la position du `h1` (`T.indexOf(h1)`) ;
- **matrice de variantes** : `document.querySelectorAll('[class*="sku"] img, [class*="Sku"] img')`
  puis les attributs `alt` dédoublonnés — c'est la recette la plus rentable de cette passe,
  elle donne la liste exacte des coloris et révèle les variantes « no logo » / « sterile » ;
- largeurs : regex sur `Largeur de bande:` ;
- **délai France réel** : regex sur `Livraison: <dates>` et
  `Service de livraison : Colissimo / Colis Privé` — donne une fourchette datée, bien
  meilleure qu'une estimation ;
- boutique : `document.body.innerHTML.match(/store\/(\d{6,})/)` ;
- note vendeur : regex `/[\d.,]+% Avis positifs/`.

### 4. Deux pièges d'outillage qui coûtent des allers-retours
- Le retour d'une extraction JS est **tronqué vers ~1 000 caractères** : découper avec
  `.slice()` et raccourcir les titres, ou faire deux appels.
- **Ne jamais renvoyer `location.href` quand l'URL contient une query string** : la réponse
  est filtrée (`BLOCKED: Cookie/query string data`) et l'appel est perdu. Renvoyer le titre
  ou le chemin seul.
- `navigate` vers un nouveau domaine peut être refusé au premier essai ; réessayer avec
  `force: true`.
- Enchaîner `navigate` → `wait 6-7 s` → **une seule** extraction JS, groupés dans un
  `browser_batch`. Deux produits par batch fonctionnent sans que l'onglet se re-navigue.

### 5. Ce qui reste vrai de v2
- La page boutique triée `?sortType=total_tranpro_desc` est bien une excellente entrée.
- Le carrousel « Articles similaires » reste la meilleure source **inter-vendeurs** : les deux
  candidats cuir à forte preuve (769 et 301 avis) viennent de là, alors que les deux boutiques
  déjà validées n'avaient que du cuir à moins de 40 ventes. À utiliser dès qu'une catégorie
  est faible chez les vendeurs connus.
- Privilégier les identifiants récents reste juste, mais la borne haute est `1005012`.

### 6. Accès fichiers (à signaler à Hakim)
macOS TCC bloque ce processus sur `~/Documents` : `ls` du dossier et **ouverture des fichiers
pré-existants** échouent (`Operation not permitted`), y compris hors sandbox — c'est pourquoi
le rapport v2 n'a pas pu être relu. En revanche l'**écriture** et la relecture des fichiers
créés par le processus fonctionnent, d'où la présence de ce v3 au bon emplacement. Pour
débloquer la lecture des passes précédentes : accorder l'accès « Dossiers » / « Disque
complet » au terminal hôte dans Réglages Système → Confidentialité et sécurité.

## Contrôles du catalogue

1. **Rabattement.** Aucune ligne « y compris pour X » sur les têtes lues.
2. **Pièce / produit fini.** Pas de pièce : tout est produit fini.
3. **Générique contaminé.** `portefeuille` : PAA finance ~10 %. `porte-cartes` : related « jeu ». `robe/jupe` : univers vêtement, retiré.
4. **Marque cachée.** Chips LV, Lacoste, Tommy, Longchamp, Guess, Cabaia — visibles, déjà au net de marque. Pas de marque cachée type « milanais ».
5. **Réparation.** `patron`, `tuto`, `coudre` dans les grappes Labs (470–2 770 cumuls thèmes) : DIY, pas dans les têtes. Pesé : hors têtes.
6. **KD.** SEMrush KD 19–28 % n’est pas utilisé. Comptage organique : page 1 = **marques FR + multi-marques**, pas Amazon (sauf 1 position homme). Porte ouverte de même nature, **dense**.

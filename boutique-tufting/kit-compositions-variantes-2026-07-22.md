## Différences clés

- **A vs B (sans tondeuse)** : A = 12 pelotes + 2 tissus + grands ciseaux, mais aucun outil ; B = 6 pelotes + 1 tissu seulement, mais ajoute lames loop/cut de rechange + kit d'outils. A est le « plus de consommables », B le « plus de pièces ».
- **SET A/B vs A/B simples** : les SET ajoutent la tondeuse à tapis électrique complète (peignes, variateur, brosse, malette) + le kit d'outils. C'est le vrai « kit complet débutant ».
- **SET A vs SET B** : composition identique, seule la couleur du pistolet change (bleu vs rose). Même prix (129,16 €).
- **SET C vs SET A** : −6 pelotes (6 au lieu de 12), −1 tissu (pas de gris antidérapant), mais + guide de tonte acrylique et 2 lames de tondeuse de rechange bien visibles ; ~21 € moins cher.

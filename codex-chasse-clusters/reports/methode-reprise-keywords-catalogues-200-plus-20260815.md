# Méthode de reprise mots-clés — boutiques de 200+ produits

Date : 2026-08-15
Objet : corriger la passe initiale des six univers à partir des catalogues concurrents transmis par Hakim.

## Pourquoi la première passe n'était pas suffisante

La première passe a surtout testé quelques têtes de marché et adjacences évidentes. Cette approche convient à un filtre rapide, mais pas à une conclusion globale sur un univers destiné à accueillir plus de 200 produits. Les concurrents fournis exposent des taxonomies beaucoup plus profondes : vêtements par coupe/style/genre, décoration par support et motif, bijoux par pierre/type/symbole, globes par corps céleste/finition/style/occasion.

L'erreur à corriger n'est pas le principe du volume-first ; c'est la couverture insuffisante de la phase de découverte avant nettoyage.

## Unité de travail

La bonne unité n'est ni « un produit = un mot-clé », ni « une collection concurrente = un cluster ». L'unité décisionnelle est une **intention commerciale pouvant légitimement être servie par une page**.

Ainsi :

- 200 produits peuvent vivre sous 20 pages de collection fortes et une longue traîne produit ;
- 200 collections Shopify peuvent se recouvrir et ne former que quelques dizaines d'intentions ;
- 500 formulations peuvent partager la même SERP et ne doivent pas être additionnées naïvement.

## Protocole par univers

### Étape A — couverture de catalogue

1. Inventorier toutes les catégories et feuilles de navigation des concurrents.
2. Dédupliquer les produits présents dans plusieurs collections.
3. Identifier les familles capables de porter au moins 20–50 références distinctes.
4. Marquer séparément les extensions de marque, licences et assortiments hors cœur.

### Étape B — dictionnaire de graines

Pour chaque famille, préparer :

- tête produit ;
- synonymes français ;
- type + attribut ;
- type + style ;
- type + motif ;
- type + audience ;
- type + usage/pièce ;
- type + occasion ;
- formulation cadeau ;
- problèmes et besoins seulement lorsque la promesse est légale et démontrable.

### Étape C — expansion SEMrush France

1. Mesurer toutes les graines, pas seulement les têtes.
2. Explorer les variantes en correspondance large/expression/exacte.
3. Extraire les mots-clés organiques des concurrents lorsque disponibles.
4. Lire la SERP des têtes et de chaque famille qui contribue matériellement au total.
5. Rechercher les acteurs qui se répètent, marketplaces, marques et pages informationnelles.

### Étape D — nettoyage

Appliquer, dans cet ordre :

1. intention d'achat ;
2. marché France ;
3. exclusions marque/IP ;
4. synonymes et variantes ;
5. page eligibility ;
6. chevauchement SERP ;
7. attribution à un seul univers ;
8. contrôle manuel des plus gros contributeurs.

### Étape E — sortie auditable

Chaque ligne conservée doit contenir au minimum :

| Champ | Rôle |
|---|---|
| mot-clé | formulation mesurée |
| volume FR | valeur SEMrush datée |
| CPC | indicateur économique, non marge |
| intention | commerciale, transactionnelle, mixte ou exclue |
| famille | collection logique |
| page canonique | page susceptible de servir la requête |
| marque/IP | oui/non + motif |
| cluster SERP | identifiant de déduplication |
| statut | conservé, exclu, chevauchement ou manquant |
| source/date | traçabilité |

## Seuil de complétude de la recherche

La recherche d'un univers n'est considérée assez large que lorsque :

- toutes les catégories feuilles des concurrents de référence ont été traduites en graines ou explicitement exclues ;
- deux expansions successives n'ajoutent presque plus de nouvelles familles commerciales significatives ;
- les termes représentant au moins 80–90 % du volume brut ont été lus ou contrôlés en SERP ;
- les principales pages concurrentes ont une destination canonique dans le modèle ;
- les exclusions et doubles comptes sont documentés ;
- le total net peut être recalculé ligne par ligne.

Ce seuil est un critère de saturation de recherche, pas une promesse que l'univers passera.

## Priorités de reprise issues des liens

1. **U5 gothique** — priorité maximale : l'écart entre sept graines mesurées et 75 collections/2 341 produits observés est trop grand.
2. **U4b déco espace** — priorité haute : mesurer lumière, mur, objets et textile ; objectif de preuve ≥18 k nets additionnels.
3. **Bijoux pierres naturelles et symboles** — nouveau candidat distinct, à mesurer sans claims et sans l'ajouter à U6.
4. **U3 globe décoratif/premium/rotatif** — reprise bornée ; utile pour la taxonomie mais concurrence de marque et profondeur produit plus faibles.

## Gates conservés

Une fois le volume propre établi :

1. prix ;
2. panier potentiel ;
3. marge potentielle ;
4. SERP et concurrence approfondie ;
5. verdict ;
6. arborescence ;
7. sourcing exact.

La profondeur concurrente justifie de mieux mesurer ; elle ne permet pas de sauter un gate.

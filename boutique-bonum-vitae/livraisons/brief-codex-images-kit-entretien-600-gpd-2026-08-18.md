## Voie C (Hakim, 18/08) — ne pas STOPPER pour les étiquettes des sources

Le STOP « marquage physique à vérifier » est **levé pour ce SKU**. Hakim assume que :

Les images Shopping ne peuvent **jamais** montrer OSWNKW, RTL, NSF, FDA, pH, « alcalin »,

## Le produit (pour comprendre ce que tu mets en scène)

**Kit d'entretien annuel** pour osmoseur 600 GPD à membrane format **3013**. Ce n'est pas
une machine. Ce sont les pièces d'usure : préfiltres, membrane, cartouches de
reminéralisation. Claire (38 ans, zone calcaire) les range dans un placard et les change
quand le débit ou le goût baisse — pas un chantier, pas un laboratoire.

Contenu annoncé (à montrer **en comptant les objets**, jamais en écrivant ×2) :

| Pièce | Qté | Silhouette à reprendre telle quelle |
|---|---|---|
| Préfiltre PP | 2 | Cylindre blanc, surface fibreuse / rainurée, plus fin que le PPC |
| Filtre composite PPC | 2 | Cylindre maille grise, bouchons gris foncé haut et bas |
| Membrane RO 3013-600 | 1 | Plus haute que les autres ; gaine **bleu vif** ; joint caoutchouc **noir** vers le haut ; tube blanc en tête ; embout bas plus étroit |
| Cartouche inline reminéralisation | 2 | Plus petite ; plastique blanc lisse ; extrémités effilées avec embouts de raccord |

Les sources se contredisent sur le **code modèle** (BW-3012-600 / BW-3013-600 /
RHF-3013-600 / RO-3013-600). **N'écrire aucun code** sur les images. La forme 3013
(plus longue que du 1812) suffit.

**Compatibilité :** revendiquée pour la famille 600 GPD 2,5 L/min déjà en catalogue.
**Non contrôlée** sur l'osmoseur 299 €. Donc : **ne jamais montrer ce kit enfoncé dans
un boîtier identifiable comme le 299 €**, ni coller une photo de l'osmoseur 449 €
dans le cadre (images dupliquées interdites). Scènes d'usage = kit posé, kit sorti
du carton, ou geste de remplacement dans un **boîtier générique non brandé**, pas
une preuve d'emboîtement sur nos machines.

Ne convient **pas** aux osmoseurs 50–150 GPD format 1812. Ne pas représenter une
petite membrane blanche type 1812.

## Règles non négociables

1. **Composition, pas génération libre.** Corps, proportions, couleurs de gaine,
   joint noir, bouchons, embouts : repris **tels quels** depuis les sources 1 et 5.
   Seule la mise en scène change (fond, décor, lumière, nombre d'exemplaires pour
   coller aux quantités). Pas de cinquième type de filtre inventé. Pas de boîtier
   machine redessiné « pour faire joli ».
2. **Aucun texte nulle part** dans l'image (contrainte flux Shopping). Pas de badge,
   pas de litre, pas de micron, pas d'étoile, pas d'avis, pas de logo, pas de
   pastille PP/PPC. Les images parlent par la scène ; le texte vit dans la fiche.
3. **Aucune imagerie santé.** Pas de peau, pas d'avant/après corporel, pas de verre
   « eau pure » avec étincelles, pas de molécule, pas de pH. Un verre d'eau posé
   sur une table de cuisine française est acceptable **s'il est banal** (pas un
   claim). En cas de doute : placard / plan de travail, sans verre.
4. **Pas de preuve sociale.** 0 commande client. Pas de note, pas de « Vérifié »,
   pas de compteur.
5. Format : **2048×2048, 1:1, JPEG sRGB**. Nommage :
   `kit-entretien-osmoseur-600-gpd-{1..6}.jpg`.
6. Chaque image livrée avec son **`alt` français descriptif** dans le `manifeste.json`.
   Alt = ce qu'on voit, sans marque tierce, sans claim.

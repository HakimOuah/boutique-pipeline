# Résultat — présélection DE (05/09/2026)

## Verdict

Résultat insuffisant : aucun marchand ne confirme simultanément petit Shopify + produit générique comparable AliExpress + offre active vérifiable pour chacune des deux familles. Recherche organique uniquement ; aucune annonce utilisée.

## 1. Schachbrett — piste écartée comme preuve de générique/drop

[STRATHMANN — Holz Schachbrett](https://shop.strathmann.cologne/products/schachbrett) — **85,00 €** pour la variante `Buche / mit` ; le JSON produit public confirme aussi `Buche / ohne` à **68,20 €** (donc hors budget). Composition affichée : **1 échiquier en bois + 1 jeu de pièces en bois claires/foncées**. Dimensions exactes : **33 × 33 × 4 cm** ; poids annoncé : **3 kg**. Le texte mentionne hêtre/chêne, mais le JSON n’expose que les variantes en hêtre.

Preuve Shopify : pied de page HTML « Powered by Shopify » et endpoint public [`/products/schachbrett.js`](https://shop.strathmann.cologne/products/schachbrett.js). Le HTML indique toutefois « Ausverkauft », alors que le JSON renvoie `available: true` : disponibilité non fiable. Aucun délai de livraison n’est affiché dans la fiche (seulement une rubrique « Versand »).

Indice de comparabilité : format simple, bois, pièces optionnelles ; mais la fiche revendique une fabrication artisanale, une « Manufaktur », du sur-mesure et des pièces faites main. C’est donc une **référence de prix Shopify**, pas un indice suffisant de générique AliExpress ni une preuve de dropshipping. Le délai, l’origine d’approvisionnement et la disponibilité réelle manquent.

Autre repère non retenu : [Des Königs — Mini Schachbrett](https://des-koenigs-schachbretter.de/products/mini-schachbrett), **79 €** (sous le seuil), **28 × 28 × 4 cm ouvert / 28 × 14 × 4 cm fermé**, 32 pièces, livraison affichée 3–5 jours (description : 4–7). La fiche le décrit également comme 100 % fait main.

## 2. Ferngesteuertes Auto — non-Shopify

[Farmers-Shop — Brave 4x4 1:14](https://farmers-shop.de/Brave-4x4-114-4WD-24-GHz-RTR-grau-ferngesteuertes-Auto) — **99,00 €**, quelques unités disponibles, délai affiché **1–2 jours ouvrés en Allemagne**. Châssis/équipement exacts affichés : **échelle 1:14, 4WD, RTR, amortisseurs à huile, suspension avant indépendante, essieu arrière oscillant, roulements à billes, différentiels métal, pneus caoutchouc, LED, batterie Li-Ion, radio 2,4 GHz**. Aucune longueur × largeur × hauteur du châssis n’est affichée dans la fiche accessible.

Le HTML public expose **JTL/JTL-Shop**, pas Shopify. Le modèle est référencé comme fabriqué par **Siva Toys / Siva GmbH** ; aucun véhicule sous licence automobile n’est visible dans le titre, mais ce n’est pas un générique Shopify vérifié. À conserver au mieux comme **référence prix/stock**, jamais comme preuve de dropshipping.

**Arrêt conformément au périmètre : aucun candidat pertinent confirmé.**
